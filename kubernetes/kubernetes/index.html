    查看 Pod 状态

    要查看当前命名空间中所有 Pod 的状态，可以使用如下命令：

    kubectl get pods

    该命令将显示每个 Pod 的名称、就绪状态（READY）、状态（STATUS）、重启次数（RESTARTS）和运行时间（AGE）。如果你想要查看特定命名空间下的 Pod，可以加上 -n 参数指定命名空间：

    kubectl get pods -n <namespace-name>

    此外，若想获得更详细的信息，比如 Pod 的 IP 地址、节点信息等，可以添加 -o wide 参数：

    kubectl get pods -o wide -n <namespace-name>

    查看 Node 状态

    检查集群中所有节点的状态可以使用以下命令：

    kubectl get nodes

    这会列出每个节点的名字、状态（STATUS）、角色（ROLES）、版本（VERSION）、内部IP地址（INTERNAL-IP）以及其他相关信息。同样地，如果需要获取更加详细的节点信息，如容量、条件、事件等，可以使用 describe 命令：

    kubectl describe node <node-name>

    查看 Pod 的详细信息

    当你需要深入了解某个 Pod 的具体配置或状态时，可以使用 describe 子命令来查看其详细信息：

    kubectl describe pod <pod-name> -n <namespace-name>

    此命令将展示包括 Pod 的规格、状态、事件历史、容器状态在内的各种详情，有助于排查问题 。

    查看 Kubernetes Events

    Kubernetes 中的事件是了解集群内发生情况的关键途径之一。你可以通过以下命令查看特定命名空间下与特定 Pod 相关的事件：

    kubectl get events --namespace <namespace-name> --field-selector involvedObject.name=<pod-name>

    这个命令可以帮助你追踪到 Pod 创建、更新或者删除过程中产生的所有事件，对于故障排查非常有用 。

    调整 Pod 副本数量

    为了调整 Deployment 中 Pod 的副本数量，可以使用 scale 命令：

    kubectl scale deployment <deployment-name> --replicas=1 -n <namespace-name>

    上述命令会将指定命名空间下的 Deployment <deployment-name> 的副本数设置为 1。这对于根据负载动态调整服务规模非常有用 。

    高级用法及注意事项

    • 编辑资源：如果你想直接修改正在运行的资源定义，可以使用 kubectl edit 命令。例如，编辑一个 Deployment 的配置可以直接执行 kubectl edit deployment <deployment-name>。
    • 应用配置文件：使用 kubectl apply -f <filename.yaml> 可以基于 YAML 文件创建或更新资源，并且适合持续部署场景 。
    • 日志与调试：除了查看 Pod 和 Deployment 的基本信息外，还可以利用 kubectl logs 来获取容器的日志输出，以及 kubectl exec 在容器内部执行命令来进行进一步的诊断 。

    当然，Kubernetes 提供了丰富的命令集来管理集群中的各种资源。以下是更多常用的 Kubernetes 命令示例和用法说明：

    资源创建

    • 创建资源：使用 kubectl create 根据 YAML 文件创建资源。 shell kubectl create -f ./nginx.yaml 或者一次性创建多个文件中定义的资源： shell kubectl create -f ./nginx1.yaml -f ./mysql2.yaml

    应用与更新配置

    • 应用配置：使用 kubectl apply 可以创建或更新资源，并且支持通过标准输入（stdin）进行操作。 shell kubectl apply -f ./nginx-deployment.yaml

    删除资源

    • 删除资源：可以通过资源名称、标签或者 YAML 文件删除资源。 shell kubectl delete pod,service baz foo kubectl delete pods,services -l name=myLabel

    查看资源详情

    • 查看详细信息：kubectl describe 可用于获取任何资源的详细信息。 shell kubectl describe pod <pod-name> -n <namespace-name>

    运行容器

    • 运行容器：使用 kubectl run 在集群中启动一个容器实例。 shell kubectl run nginx --image=nginx:1.10 --port=80

    暴露服务

    • 暴露服务：利用 kubectl expose 创建一个新的服务并暴露给外部访问。 shell kubectl expose deployment nginx --port=80 --target-port=8080 --type=NodePort

    日志与执行命令

    • 查看日志：kubectl logs 用来查看容器的日志输出。 shell kubectl logs -f <pod-name>
    • 在容器内执行命令：kubectl exec 允许你在容器内部执行命令。 shell kubectl exec -it <pod-name> -- /bin/bash

    部署管理

    • 部署伸缩：除了前面提到的 scale，你还可以设置自动伸缩策略。 shell kubectl autoscale deployment <deployment-name> --min=3 --max=5 --cpu-percent=80

    状态检查

    • 滚动更新状态：对于 Deployment 类型的资源，你可以检查其滚动更新的状态。 shell kubectl rollout status deployment/<deployment-name>

    回滚更新

    • 回滚到之前的版本：如果需要回滚 Deployment 到上一个版本，可以使用以下命令。 shell kubectl rollout undo deployment/<deployment-name>

    资源管理

    • 获取所有资源：查看当前命名空间下的所有资源。

    shell kubectl get all

    • 获取特定类型的资源：例如获取所有的 Services。 shell kubectl get services

    集群信息

    • 集群信息概览：查看整个集群的基本信息。 shell kubectl cluster-info

    资源限制与配额

    • 设置资源请求和限制：可以在 YAML 文件中定义容器的资源请求（requests）和限制（limits），也可以通过 kubectl set resources 动态调整。 shell kubectl set resources deployment <deployment-name> --limits=cpu=200m,memory=512Mi --requests=cpu=100m,memory=256Mi

    网络策略

    • 创建网络策略：为 Pod 定义网络访问规则。 shell kubectl create -f network-policy.yaml

    持久存储

    • 创建 PersistentVolumeClaim (PVC)：用于申请持久化存储。 shell kubectl create -f pvc-definition-file.yaml

    • 绑定 PVC 到 Pod：在 Pod 的 YAML 文件中指定 PVC 来挂载持久卷。

    用户认证与授权

    • 创建角色和角色绑定：为了实现细粒度的权限控制。 shell kubectl create role pod-reader --verb=get,list,watch --resource=pods kubectl create rolebinding read-pods --role=pod-reader --user=jane

    自动扩展

    • 水平自动扩展器 (HPA)：基于 CPU 使用率或其他指标自动扩展 Deployment 中的副本数。 shell kubectl autoscale deployment <deployment-name> --min=3 --max=10 --cpu-percent=80

    日志与监控

    • 查看事件：获取集群或特定命名空间中的事件。 shell kubectl get events

    • 查看节点资源使用情况：需要 Metrics Server 支持。 shell kubectl top nodes kubectl top pods

    其他高级操作

    • 端口转发：将本地端口转发到 Pod 内部的服务端口。 shell kubectl port-forward <pod-name> 8080:80

    • 文件传输：在宿主机和容器之间拷贝文件。 shell kubectl cp /path/to/local/file <namespace>/<pod-name>:/path/in/container/

    • 标签和注解：为资源添加或修改标签和注解。 shell kubectl label pods <pod-name> new-label=value kubectl annotate pods <pod-name> description="This is a test pod"
