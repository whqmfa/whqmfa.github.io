将 MkDocs 项目部署到 GitHub Pages 指南

准备工作

确保本地已安装并配置好 MkDocs 项目，并能通过 mkdocs serve 正常启动站点。

mkdocs new .
mkdocs serve

安装必要工具

使用 pip 安装 MkDocs 及其 Material 主题：

pip install mkdocs mkdocs-material

创建 GitHub 仓库

  1. 在 GitHub 上创建一个新的仓库。
  2. 记录下新仓库的 URL（例如：https://github.com/username/repository.git）。

初始化 Git 并推送至 GitHub

在 MkDocs 项目根目录执行以下命令：

cd path/to/your/mkdocs/project
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/username/repository.git
git push -u origin main
or
# 在页面创建好之后拉取
git clone https://github.com/whqmfa/whqmfa.github.io.git
cd whqmfa.github.io
mkdocs new .
mkdocs gh-deploy
​```

部署到 GitHub Pages

运行以下命令以部署 MkDocs 站点到 GitHub Pages：

mkdocs gh-deploy

此命令会将生成的站点文件推送到仓库的 gh-pages 分支。

配置 GitHub Pages

  1. 打开 GitHub 仓库页面，进入 Settings。
  2. 在侧边栏找到 Pages 部分。
  3. 设置 Source 为 gh-pages 分支。

访问与更新

  • 访问: 站点可通过 https://username.github.io/repository/ 访问。
  • 更新: 修改内容后，再次运行 mkdocs gh-deploy 更新站点。

注意事项

  • .gitignore 中应包含 site/ 目录，避免提交生成的站点文件。
  • 修改 MkDocs 配置前请先本地测试，确保无误后再部署。
